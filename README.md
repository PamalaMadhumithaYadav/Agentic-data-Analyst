# LLM Analytics Agent

An LLM-powered agent that performs data analytics using natural language queries.
The agent can analyze CSV and JSON data and will later support database connections
(PostgreSQL, Oracle, etc.).

## Vision
Build an intelligent analytics agent that:
- Understands datasets and schemas
- Plans multi-step analysis
- Executes SQL / Python tools
- Explains results clearly

## Current Status
🚧 Project initialization (repository + structure)

## Planned Features
- CSV & JSON ingestion
- Agent-based query planning (LangChain)
- SQL & Pandas tool execution
- Safe query guardrails
- Interactive UI
